Remotionvídeo feito em código

01/05

Você descreve o vídeo e o Claude escreve e renderiza a animação inteira em código. Sem editor de vídeo.

Instalar
npx create-video --yes --blank meu-video
cd meu-video
npx remotion skills add
npm run dev

Depois, em outro terminal na mesma pasta, abra o Claude:

claude
Peça assim

Crie um vídeo vertical de 15s com meu logo entrando e o slogan aparecendo embaixo.

remotion.dev ↗

Voiceboxclona sua voz, grátis e open source

02/05

Faz o que o ElevenLabs faz, mas de graça e rodando no seu computador: clona sua voz com poucos segundos de áudio e o Claude passa a falar com ela.

Instalar

1. Baixe e abra o app em voicebox.sh ↗

2. Com o Voicebox aberto, conecte no Claude Code:

claude mcp add --transport http voicebox http://127.0.0.1:17493/mcp --header "X-Voicebox-Client-Id: claude-code"
Peça assim

Lê esse roteiro com a minha voz clonada e salva o áudio.

⚠ Roda melhor em Mac com chip Apple (M1 ou superior) ou PC com placa de vídeo. Sem isso funciona, mas fica bem mais lento.

Link
github.com/jamiepine/voicebox ↗

Playwrighto Claude mexe no navegador sozinho

03/05

O Claude abre o navegador, clica, preenche formulário e tira print, tudo sozinho. Ótimo pra testar site e automatizar tarefa repetitiva.

Instalar
claude mcp add playwright npx @playwright/mcp@latest
Peça assim

Abre meu site, preenche o formulário de contato com dados de teste e me manda um print do resultado.

Link
github.com/microsoft/playwright-mcp ↗

Figmadesign vira código de verdade

05/05

Você cola o link do design e o Claude transforma a tela em código, seguindo cores, textos e espaçamentos do Figma.

Instalar
claude mcp add --scope user --transport http figma https://mcp.figma.com/mcp

Depois, dentro do Claude: /mcp → figma → Authenticate.

Peça assim

Transforma essa tela em código: [cole o link do frame do Figma]

Link
developers.figma.com ↗
